# Demographic Globe

Interactive 3D globe of world demographic indicators (1950–2100), built for the ASA International Data Quest 2026 by Team Ipanema (ABE-L).

**Live site:** https://carvguilherme8.github.io/demographic-globe/

Drag to rotate, scroll to zoom, click a country for its sheet (indicators, population fan chart with 80% and 95% prediction intervals, fertility and life-expectancy history). Nine map layers, a 1950–2100 timeline, and a PT/EN toggle.

## Data and credits
- Demographic data: United Nations, Department of Economic and Social Affairs, Population Division (2024). *World Population Prospects 2024* (Medium variant and probabilistic prediction intervals). See https://population.un.org/wpp/ for the terms of use.
- Country boundaries: [Natural Earth](https://www.naturalearthdata.com/) (public domain).
- Rendering: [globe.gl](https://globe.gl/) and three.js (open source).

`index.html` is a single self-contained file (libraries and data embedded), so it also works when opened locally without internet.
